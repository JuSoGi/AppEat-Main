# AppEat 🍽️

Aplicación web para la gestión de donaciones de alimentos entre supermercados y fundaciones.

---

## 🚀 Tecnologías utilizadas

- React
- Node.js (en proceso)
- Express (en proceso)
- PostgreSQL (en proceso)

---

## 🎯 Funcionalidades actuales (MVP)

- Inicio de sesión (simulado)
- Visualización de productos
- Registro de nuevos productos
